# 🖥️ Personal Portfolio OS

> Not just another portfolio website.

This project is a personal portfolio built with Next.js, designed to feel like a desktop operating system rather than a traditional webpage.

Instead of scrolling through sections, visitors can explore projects, experience, and information through interactive windows, just like using a real computer.

## ✨ Features

- Desktop-inspired user interface
- Draggable and focusable windows
- Interactive project explorer
- Responsive design
- Built with Next.js and TypeScript
- Modern component-based architecture

## 🚀 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## 🛠️ Development

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## 📌 Status

Currently under active development.

New features, animations, and desktop interactions are being added incrementally.
